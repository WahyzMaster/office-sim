How should Commit, Push, Open PR, CI Pass/Fail, Merge, Pull, and Cleanup work?

Long image

A

Answer

Run every branch through a deterministic seven-stage Ship and Land pipeline inside .worktrees/<name>, wait for MERGED confirmation, and fast-forward the primary checkout before pruning.

  1. Never run gh pr merge --delete-branch from a secondary worktree; GitHub CLI attempts git checkout master locally and fails when master is checked out in the primary root.1
  2. Rebase onto origin/master before pushing and when base-branch drift occurs so shallow CI checks and merge queues have a clean linear parent.2
  3. Wait for state == "MERGED" (mergedAt != null) before removing the worktree, then run git pull --ff-only, git worktree remove, git branch -D, and git worktree prune from the primary repo root.3
  4. Close the loop by transitioning the linked Linear GLO-<n> issue from In Review to Done upon merge verification.4

How do the seven stages flow from worktree commit to final cleanup?

Diagram structure
  • 1. Verify and Commit commit
  • 2. Push and Open PR pushpr
  • 3. CI Watch Loop cicheck
  • 3b. Rebase or Fix CI cifix
  • 4. Squash or Queue Merge merge
  • 5. Pull Primary Root pull
  • 6. Prune Worktree and Branch cleanup
  • 7. Close Linear GLO linear
  • cicheck → cifix · fail or drift
  • cicheck → merge · all gates green
  • cifix → cicheck · force-with-lease
  • cleanup → linear · GLO Done
  • commit → pushpr · Conventional title
  • merge → pull · mergedAt confirmed
  • pull → cleanup · cd MAIN_ROOT
  • pushpr → cicheck · gh pr checks
  1. 1. Verify and Commit ↗

    Run verify_session_delta.sh, rebase onto origin/master, stage explicit paths, and commit with type(scope): subject (GLO-<n>).

  2. 2. Push and Open PR ↗

    Push with -u origin <branch>, create PR with gh pr create, and move GLO-<n> to In Review.

  3. 3. CI Watch Loop ↗

    Inspect checks via gh pr view or gh-fix-ci (inspect_pr_checks.py).

  4. 3b. Rebase or Fix CI ↗

    On base-branch drift, rebase onto origin/master and --force-with-lease; on test/lint failure, fix in worktree and push.

  5. 4. Squash or Queue Merge ↗

    Run gh pr merge --squash (or --auto --squash for Merge Queue) WITHOUT --delete-branch.

  6. 5. Pull Primary Root ↗

    Confirm mergedAt != null, cd to $MAIN_ROOT, and run git fetch --prune origin && git pull --ff-only origin master.

  7. 6. Prune Worktree and Branch ↗

    Run git worktree remove, git worktree prune, git branch -D <branch>, and git push origin --delete <branch>.

  8. 7. Close Linear GLO ↗

    Transition GLO-<n> from In Review to Done and record the merge commit SHA.
